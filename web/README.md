# arcanum（v2.2）

文字驱动的沙盒生活模拟 RPG。当前已包含生活循环、学校、社交、事件、学期、演武场切磋与商业区扩展，用 Vite + React + TypeScript + Zustand 构建。

## 在线试玩与手机安装

```text
https://l-close.github.io/arcanum/
```

- 手机浏览器打开后，选择“添加到主屏幕”
- 首次加载完成后支持离线游玩
- 存档保存在手机浏览器的 localStorage 中

## Android APK

APK 由 GitHub Actions 云构建，不需要本地 Android SDK：

1. 打开仓库的 **Actions**
2. 选择 **Build Android APK**
3. 点 **Run workflow**，选择 `main`
4. 构建完成后在该次运行页面下载 `arcanum-debug-apk`

这个 APK 使用 debug 签名，适合自己和朋友安装，不适合上架。

## 运行

```powershell
cd web
npm.cmd install
npm.cmd run dev
```

打开终端输出的地址（通常是 `http://localhost:5173`）。

生产构建：

```powershell
npm.cmd run build
npm.cmd run preview
```

## 已实现

- 角色创建：姓名、性别（男 / 女）
- 序章 + 第一天 13 个脚本场景（逐节点移动 + 等待，选择影响属性与好感）
- 24 小时时钟：行动推进时间，00:00 切换日期
- 地图改为节点 + 连接：地点之间用显式出口连接，移动时间按最短路径累加
- 银月城与城外同级；银月城 → 长明学院 / 孤儿院 / 商业区 / 教堂 → 房间
- 城门连接城内与城外，由骑士团看守；城门 06:00–22:00 开放，只限制出城，回城永远放行
- 夜里从城门回城时，骑士会开侧门；首次有一段台词，之后只给简短提示
- 城外包含墓园与森林，目前没有专属行动与战斗
- 移动：同区 5 分钟；银月城 → 城门 → 城外 → 墓园 / 森林，单程 15 分钟
- 第一天路线按节点逐步指引；提前到达可用「等到 HH:MM」跳过等待
- 剧情与自由玩法共用同一套地点、行动、去别处界面
- 行动：听课 / 摸鱼、自习、练习格斗 / 剑术、吃饭、睡觉、闲聊、等待、打工、祷告、原地休息
- 后院加入格斗 / 剑术练习：30 分钟，体力 -4，技能经验 +2；不计入体术课程掌握度
- 打理后院：2 小时，5 铜，体力 -10；每天最多 1 次，每周最多 5 次
- 地点描述按早晨 06:00–11:00、白天 11:00–18:00、夜晚 18:00–06:00 三套切换
- 室外地点再按季节拆分时段描述：12 个地点 × 4 季 × 3 段，共 144 句；只写时间、活动与温度，不写晴雨
- 天气：晴 / 多云 / 阴 / 雨，冬季额外有雪；按天数确定性生成，顶栏显示，无数值影响
- 室外描写按「地点 × 季节 × 天气」融合成一句：12 个地点 × 16 种组合，共 192 句；冬天只写晴 / 多云 / 阴 / 雪
- 房间下方显示当前在场的有作息 NPC：米娅、卢卡、诺拉、格蕾塔；教会 NPC 暂不显示
- 演武场练习仍给体术课程掌握度 +0.25
- 用餐：每个窗口只能吃一次（体力 +12），两个食堂共用一个计数，00:00 重置；吃过后面板显示提示
- 米娅占座视为吃过午餐；已吃过午餐时“坐下一起吃”置灰
- 生命：独立于体力的战斗资源；上限 60 + 体质 × 10；睡眠每小时恢复 5 点；伤药恢复 20 点
- 睡觉：保留 1–8 小时按钮，并可直接选择睡到几点；最短 1 小时、最长 12 小时、5 分钟步进；默认当前时间 +8 小时
- 睡眠不足 4 小时只推进时间，不恢复体力、精神、生命、魔力或心情；4 小时以上按分钟比例恢复；7 小时以上额外体力 +10、心情 +1
- 每天 00:00 若心情高于 60，则心情 -1；不高于 60 时不回落
- 演武场切磋：木桩（不会还手）、练习人偶（会还手）；森林走走有 25% 概率遇到史莱姆；生命归零只判负并保留 1 点
- 战斗使用行动条：自动充能，玩家满条时暂停等待选择；本版没有防御
- 战斗行动：攻击（格斗 / 剑术）、法术、物品、认输；野外战斗为逃跑
- 剑术需要主手装备剑；本版新增练习短剑；用剑时不能施法
- 火球术：自然系·火，8 魔力，单体伤害；法术导论掌握度 20 后学会
- 战斗时间：每次行动记 1 分钟，结束后统一推进；战斗中途不触发事件
- 战斗经验：胜利后按本场使用过的技能结算，每个技能一次；木桩 expValue 0.5、练习人偶 1、史莱姆 0.8；失败/认输不给；暂不设每日上限
- 史莱姆胜利后 60% 概率掉落史莱姆凝胶；逃跑与失败不掉落
- 物品分三类：消耗品、装备、材料；材料不能装备或使用，只能在杂货店出售
- 史莱姆凝胶：普通材料，杂货店收购价 3 铜，可单卖或全部卖出
- 杂货店收购栏只显示材料，不收购装备与药品；出售不推进时间
- 墓园：扫墓 30 分钟，体力 -2，心情 +2，不设上限；守墓人只出现在描述里
- 森林：走走 15 分钟，体力 -1，心情 +1，不设上限；25% 概率遭遇史莱姆
- 野外战斗界面标题为「森林 · 遭遇」，失败或逃跑后留在森林
- 敌人详细数值见项目根目录《敌人数据.md》
- 原地休息：体力低于 20 时出现，30 分钟恢复 5 点体力，回到 20 后消失
- 等待：面板选择 5 / 15 / 30 / 60 分钟，只推进时间，不写日志
- 社交：到达地点后点击人物进入人物界面；每次闲聊 15 分钟，每位人物每天第一次 +1 好感
- 人物按时间表出现：米娅每天 11:30–12:30；卢卡工作日 07:30–08:30 / 18:00–19:00、周末 09:00–10:00 / 14:00–15:00 / 20:00–21:00；诺拉每天 06:30–21:30
- 闲聊跨过对方离开时间时，自动退回地点界面
- 对话分三档（0–19 / 20–59 / 60+），米娅、卢卡、诺拉各自有不同语气
- 关系页面：好感数字、心形、今日是否已聊与当前印象
- 米娅、卢卡各有一次性第 0 步事件：好感 ≥ 20、在对应地点触发，之后不再出现
- 四槽装备（主手 / 副手 / 护甲 / 饰品）；施法需要主手媒介，法术导论课不检查
- 物品界面：左侧 2×2 装备槽、右侧 6×4 背包、底部详情、品质配色、手写像素 SVG 图标
- 杂货店：每日库存、购买、收购材料、打工
- 武具店：练习短剑、铁剑；只买不卖，不卖护甲；库存按地点独立
- 酒馆：营业 17:00–次日 04:00；格蕾塔 17:00–次日 04:00；打工 18:00–02:00；来一杯 17:00–03:45；听人聊天 18:00–03:30
- 听人聊天：15 分钟，心情 +1，随机显示一段 2–3 行酒馆场景；学识 0 档时约 50% 概率学识 +1，达到启蒙后不再给学识
- 酒馆饮品：麦酒、果酒、蜂蜜水、热茶；不设醉酒状态
- 格蕾塔使用内置熟悉度，不显示数字、阶段或心形，不进入关系页；只影响对话
- 重要 NPC（米娅、卢卡、诺拉）仍使用好感、心形和个人事件
- 教堂：每天三次有效祷告，之后可继续但无收益
- 教堂新增救济院与钟楼；救济院可整理捐赠、照顾病人、接受治疗；钟楼可登高
- 救济院照顾病人：每天 40% 概率有病人，每天一次，1 小时，体力 -3，心情 +2
- 救济院治疗：30 分钟，5 铜，生命 +20，每天一次
- 还不上时诺拉介绍救济院义工；解锁后永久开放，2 小时 8 铜，每天一次
- 钟楼登高：30 分钟，体力 -2，心情 +1，08:00–18:00 开放
- 教堂 NPC 伊莎贝尔、玛尔塔、奥托、莉安、塞缪尔暂不做好感，不进关系页
- 教会内部只有首席修女与大修女知道神明真相；本地修女长不知情也不会察觉
- 区域列表标题按区域变化（学院设施 / 房间 / 店铺 / 厅堂）
- 事件系统：23 个事件，进入地点或行动结束触发；每天最多 3 个，间隔 30 分钟，同一事件冷却 3 天
- 一次性事件：触发时写入 `seen`，之后永久排除；支持 NPC 在场、好感下限、flag / notFlag 条件
- 调试面板“选择事件…”可按地点列出全部事件，强制触发且不写入一次性记录
- 事件选项会消耗或恢复体力、精神、心情、金钱、经验与好感；精神或金钱不足时选项置灰
- 事件选项下方显示效果摘要，例如“5 分钟 · 金钱 -1 · 心情 +2”；无变化时显示“无变化”
- 长明学院事件达到第三档（2 档）后不再给经验；孤儿院事件达到第二档（1 档）后不再给经验；街角的旧书摊达到第三档后不再给学识经验
- 达到事件经验上限时，摘要删除该经验，选完后提示“你已经很熟练了，无法再从这件事中获得经验。”

- 课后事件在最后一段结束后触发
- 讲堂不再自由自习；没课时只能预习下一节课，自动匹配古典文学或法术导论，效果与原自习一致
- 藏书阁仍可自由自习古典文学 / 自然系
- 课程掌握度：古典文学 / 法术导论 / 体术各自累计，不设上限，只影响考试

- 掌握度来源：听课、对应自习、讲堂预习、体术练习

- 假期讲堂关闭，藏书阁开放

- 假期（暑假 84–111 / 寒假 196–223）：学院设施照常开放，课程与考试暂停

- 假期可在孤儿院陪孩子们：1 小时，体力 -3，心情 +2，诺拉好感每天 +1

- 圣祷准备：周日 08:00–09:00，1 小时，体力 -4，心情 +1

- 冬夜圣祷：第 216 天 18:00–21:00，三阶段，每段精神 +2 / 心情 +2；准备 16:00–18:00，2 小时，体力 -7，心情 +2

- 底部栏只保留展开 / 收起状态和玩家名
- 深色 DoL 风格布局，无角色立绘
