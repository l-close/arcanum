# arcanum（v2.24.2）

文字驱动的沙盒生活模拟 RPG。当前已包含生活循环、学校、社交、事件、学期、演武场切磋、商业区扩展、魔法城市设施、星象台与装备打造，用 Vite + React + TypeScript + Zustand 构建。

## 在线试玩与手机安装

```text
https://l-close.github.io/arcanum/
```

- 手机浏览器打开后，选择“添加到主屏幕”
- 首次加载完成后支持离线游玩
- 存档保存在手机浏览器的 localStorage 中

## Android APK

APK 由 GitHub Actions 云构建，不需要本地 Android SDK。默认**不随网页更新自动构建**：

1. 打开仓库的 **Actions**
2. 选择 **Build Android APK**
3. 点 **Run workflow**，选择 `main`
4. 构建完成后在该次运行页面下载 `arcanum-debug-apk`

也可以用 `apk-vX.Y.Z` 标签触发；普通的 `vX.Y.Z` 标签只作网页版本记录，不会构建 APK。

建议节奏：网页随时更新，APK 每 3–5 次网页更新或一次大功能完成后构建一次。

这个 APK 使用 debug 签名，适合自己和朋友安装，不适合上架。

已接入固定签名（GitHub Secrets 已配置）。CI 会使用固定 keystore；固定签名后的第一版仍需卸载一次，之后可覆盖更新。未配置 Secrets 时会回退到临时 debug 签名。

## 版本号规则

版本号格式：

```text
主版本 . 小版本 . 补丁
x      . y      . z
```

| 位 | 含义 | 例子 |
|---|---|---|
| x 主版本 | 大版本、学年篇、大规模重构 | 第二版 → 第三版 |
| y 小版本 | 新内容包、新系统、新区域、新课程 | 药剂工坊、城市四季、西镇阶段 2 |
| z 补丁 | 修复、UI、文本、平衡、小功能 | 地图布局、换武器、掉率调整 |

边界：

```text
新系统 / 新区域 / 新课程 / 一整包新事件 → 小版本
现有系统里的小功能、按钮、UI、文本、数值 → 补丁
```

几个小补丁连续发布时，继续加第三个数字，不升小版本。

例如：

```text
v2.21.0 药剂工坊 + 工坊区 + buff → 小版本
v2.21.1 换武器 → 补丁
v2.21.2 / v2.21.3 地图布局 → 补丁
v2.22.0 魔法城市设施 → 小版本
```

每次发布需要同步：

```text
web/package.json 的 version
web/android/app/build.gradle 的 versionName
README 标题
游戏内页脚（读取 package.json）
Git 标签 vX.Y.Z
```

APK 另有独立递增的 `versionCode`：

```text
每次 APK 发布 +1
不参与 x.y.z 的语义
```

APK 标签：

```text
apk-vX.Y.Z
```

已经发布的版本号和标签不回头修改，规则从下一个版本开始执行。

## 运行

```powershell
cd web
npm.cmd install
npm.cmd run dev
```

打开终端输出的地址（通常是 `http://localhost:5173`）。

生产构建：

```powershell
npm.cmd run build
npm.cmd run preview
```

内容校验：

```powershell
npm.cmd run validate:content
```

检查地点、NPC 作息、商店库存、配方、课程、事件与剧情的地点 / 物品 / NPC 引用，以及时间窗、价格、库存和基础数值。`npm.cmd run build` 会通过 `prebuild` 自动先跑一次；确认校验器误报时可用 `npm.cmd run build --ignore-scripts` 临时跳过。
